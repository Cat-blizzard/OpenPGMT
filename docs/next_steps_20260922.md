## 1. 已有证据支持继续有界站立学习

两次左踝峰值都与跌倒触地同步，原始/缓存/目标/接触更新时间一致，较大的 PD 估计出现在
峰值后一个子步。没有发现需要先修改奖励、PD 或终止规则的接口错误。
但子步末速度与位置差分明显不同，当前数据不能认证求解器冲击幅度的物理准确性。
保留完整速度监控，在后续站立学习中区分失稳前异常与跌倒接触事件；不把消灭所有 >45 峰值
设为新增门槛，也不据此认定硬件安全或完整物理正确。

下一批可采用已登记的两条件三种子、每组 16×24×100 更新，共 **230400 transitions**。
从匹配的新初始策略开始，使用冻结静止参考与四起点，初始参数仅 Actor 目标偏置不同。
保持 PD 80/2、奖励权重、网络、PPO、物理设置与终止规则，继续按原 1000 更新学习率日程。
旧两个 20-update checkpoint 保留作诊断证据，不作为事后选择的学习起点。

非有限状态或明确接口错误保存停止；达到预算立即保存并释放 GPU，不自动延长至 200/500 更新。

KL、优势/梯度和奖励分项判断后续单变量实验，不凭更新数直接认定学不会。

## 3. v3 继续隔离，下一项 CPU 工作针对联合支撑

v3 修正上肢对应/骨长目标，保持有界源腰姿态，采用连续根高度支撑优化。
三段 IK 引入的慢走腰贴限已消除，八段恢复了部分接触；原数据/v1/v2 均保留。
仍有 9.5%–45.3% 的源支撑脚样本超出 2 cm，slow_walk_0 源映射自身仍有 70.7% 贴限，
部分关节峰速上升，50 Hz 插值有最深 0.583 mm 穿地和 0.2%–1.4% 标签差异。
因此 v3 的 `training_approved=false`，不能直接扩展到全库。

CPU 下一步优先：

1. 在原固定八片段上，针对当前根高度无法同时满足双脚支撑的帧，设计根与腿部关节的联合
   支撑约束；保留源运动残差与时间连续性，不再只改变一个高度量。
2. 对源支撑代理本身作检查，尤其是双脚静止但高度不同的时段；将确实不可达的源姿态与
   源平面/标签不确定性分开记录。源姿态越限不能靠清零腰或扩大机器人限位掩盖。
3. 同时检查最终 50 Hz 插值几何与接触查询，处理离散帧合格、插值后不一致的问题。
4. 有证据后另存新版本，仍比较限位、身体/方向误差、支撑期脚间隙、摆动抬脚和根/关节连续性。
   不能用新目标上的优化残差直接宣称超过旧目标，也不能用错误的旧解剖对应作为最终质量评价。

这些是离线重定向约定，RL 奖励和控制参数保持。参考工作不阻塞已验证静止参考上的站立学习；
准备加入运动片段时，才要求该批数据通过参考质量与受控物理跟踪检查。
