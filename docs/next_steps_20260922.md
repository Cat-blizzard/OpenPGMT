## 1. CPU 审查与诊断准备（最高优先级）

### 执行器配置

逐关节对照 URDF、USD 和 IsaacLab 最终配置，列出名字映射、effort/velocity
限值、stiffness/damping、默认姿态和单位。当前统一 120 Nm 的配置会覆盖物理
力矩上限；URDF 中 wrist pitch/yaw 为 5 Nm、肩/肘为 25 Nm、膝为 139 Nm。
确认当前 USD 对应的机器人版本后，建立有来源的逐关节配置，不直接将某一
文件的数字视为论文作者的实际控制器参数。

先单独改变确认有误的限值，再决定是否调整 PD，避免同时更改两者而无法归因。
使用命名映射和回归检查防止 Isaac 运行时关节顺序与参考数据顺序混淆。

### 捕获异常所需的记录

补充有界的事件快照，限定数量和写盘频率，避免显著增加训练成本：

- 超速关节的名字、实际速度、目标角度、实际力矩、力矩饱和比例；
- reset 后的姿态/速度、第一步目标、延迟队列和动作历史，追踪首步控制冲击；
- 四个末端各自的机器人加速度、参考加速度和误差，附带 dt、序列、帧号、
  episode 年龄，区分重置边界、参考尖峰与物理运动；
- KL 异常样本的普通/恢复标签、观测、Normal 参数和更新前后快照，支持 CPU
  重放，并核查共享 IFM 的更新与观测尺度。

现有训练日志只保存聚合量，不能据此重建第 179 轮的具体异常状态。准确归因
需要下一次短物理运行捕获样本，随后尽量用 CPU 重放完成优化诊断。

CPU 阶段交付：执行器对照表、配置候选、诊断实现和相关回归检查。保留 v4
源码快照、初始/最终 checkpoint 与原始数据；数据修正使用新版本并记录变换。

## 2. 最小物理对照（安排 GPU 时执行）

先做无学习的执行器响应与短运动检查，再做 16 环境、约 20 次更新的接口复验。
固定动作/参考片段、初始条件和随机种子，一次只改一个因素：

1. 当前执行器配置与经资产核实的逐关节限值配置；
2. 在选定执行器配置下，对比当前默认 reset 与参考状态初始化；
3. 捕获典型超速、加速度尖峰和 recovery KL 异常样本。

参考状态初始化需要同时核对 q、qd、root pose/velocity、落地高度、历史缓存及
首步控制目标。它未被 PGMT 明确规定，不预先认定优于默认姿态。不得通过隐式
替换 rollout 中的策略动作来消除首步冲击；如设置 episode 外的预热，必须显式
记录，并在相应比较中保持一致。

静态姿态和少量简单运动只作为物理诊断，不替代全运动库训练。单纯 reference
PD 播放也不是可靠的动态平衡控制器，播放失败不能单独证明 PPO 或参考数据有错。

进入下一步的条件：关节映射/单位/限值正确，主要异常有可定位的触发条件，
修改实际作用于物理执行器，短 PPO 运行有限且每轮仍有有效更新。不可用提高
终止阈值、延长恢复宽限或直接缩小奖励权重来替代定位。

## 3. 根据捕获样本修正 PPO 尾部更新

保持 v4 的平均 KL 预算和日志。优先修复可验证的观测、尺度或实现问题；若
极端更新仍存在，再对普通/恢复分组预算与极端样本保护做同批 CPU 对照。
仅增加 p99 阈值不足以处理当前证据：seed 1 第 179 轮 p99 只有 0.0255，
一个 recovery 状态的 KL 却达到 16.28。

新增阈值须作为工程假设登记。验收同时检查尾部更新降低、actor 仍能有效更新、
回退后 Adam 状态正确、critic completion 不改变 actor/共享编码器，以及
checkpoint 可恢复性。不能以所有更新被拒绝换取漂亮的 KL 数字。

## 4. 验证策略确实能学习

先用少量固定的站立/简单动作片段做可学习性诊断，随后回到完整 77 段参考库、
recovery pool 和 adaptive sampling。诊断子集的成绩不作为论文结果。

建议先用单个种子的 16 环境短跑排除接口故障，再对选定候选做 64 环境的三种子
学习对照。按 transitions 预先限定预算，200 更新仅作首个检查点；是否延长到
500 或增加环境数，由匹配条件下的行为趋势和物理诊断决定，不预设 200 必须
学会全库跟踪或恢复。学习率日程在启动前确定，停止点独立设置。

比较必须固定非实验变量：参考和初始状态清单、动作分布初始化、随机化、奖励、
终止规则、采样策略、优化参数及数据版本。critic completion 本阶段固定，不
再同时改动；要证明其独立收益，另做同样本预算的开/关多种子对照。

继续扩大训练的证据：简单动作已出现可重复的学习趋势；在同一评估协议下，
三种子的存活/完成情况和跟踪误差整体改善，且没有用更差的跟踪换取表面存活。
恢复另外记录“3 秒内重新站稳”和“后续存活”，与正式的 30 秒完成指标分开。
不设未经依据的论文成功率门槛，也不要求小诊断预算达到最终论文成绩。

## 论文复现边界

保留关节位置目标 + PD、共享 IFM、多头 critic、Table I 奖励项和权重、恢复课程、
自适应采样及两阶段流程。逐关节 PD、普通 reset、KL 约束等未公开实现细节应
明确登记为独立复现假设，不称为作者原始配置。

[RGMT §II-D](https://arxiv.org/html/2601.23080v1#S2.SS4) 写出恢复窗口和早期辅助
拉力；PGMT 引用其恢复训练，但没有明确给出是否照搬辅助力及全部参数。当前
主实现继续不加辅助外力；如以后需要研究，作为清楚标注的独立消融。
