### A/B 的解释边界

- 四个起点是固定姿态微扰，独立训练种子只有三个；随机模式每种子只有一条固定噪声带。
- t0 的初始观测相同，后续状态会随策略分岔。共同窗口仅统一评分时段，不代表后续状态也相同。
- 评估产物明确保存初始观测和逐步物理状态，不能把物理状态数组直接当作含历史编码的完整策略观测。需要同状态策略对照时，先使用已存初始观测或训练 capture 中的完整观测，避免未经验证地重建历史。
- 静止参考关节姿态与载荷补偿控制目标分别比较：关节目标偏离 q=0 不必然是错误；控制目标与实际跟踪姿态不能混淆。
- 身体 RMSE 在各自 root/yaw 局部系计算，世界系根高度另列；接触力和隐式 PD 力矩估计的来源、时序分别标注。

### C 的具体计算

设 `g_upper/g_lower/g_aux` 为与当前 PPO 一致、各头优势标准化后的**损失参数梯度**。只在 CPU 计算：

```text
d(λ) = -(g_upper + g_lower + λ * g_aux) / (2 + λ)
λ = 1：训练当前使用的三头等权方向
λ = 0：移除归一化后辅助头贡献的诊断方向
```

不施加任何参数更新。使用同一快照、同一 rollout、同一优势和同一初始观测，仅改变 λ。通过对应策略的 Jacobian 计算 `J d(λ)`，再与目标角变化、静态载荷目标方向比较；参数梯度和动作向量不能直接点积。方向余弦与原始范数同时报告，零范数标记为不可定义。

确定性目标与固定噪声下目标分别映射：确定性目标不依赖 `log_std`，其对应 Jacobian 列为零；随机目标需包含 `log_std` 的影响。共享 history/IFM 参数也纳入，不能只看 Actor 最后一层。

另取保存的实际已接受参数变化 `Δθ`，比较 `J Δθ` 与真实 before/after 首动作变化，报告线性化残差。用适当小的对称有限差分检查 JVP 符号/实现，并核对 λ=1 的组合与既有三头平均梯度相符。这些检查验证 CPU 分析器，不是物理验收。

第 20/100 更新的局部梯度不涵盖全部训练历史、PPO 裁剪和 Adam 路径。因此结果最多支持一个待检验机制，不能直接断言辅助头导致跌倒，也不能把 λ=0 的梯度方向当作训练后的行为结果。统一缩放某一头全部奖励可能被逐头优势标准化抵消，不作为首选干预。

## 2. CPU 结果决定下一分支

|观察结果|下一步|
|---|---|
|发现动作复算、关节映射、观测历史或时序不一致|先修正具体接口并增加针对该错误的检查；再登记最小物理复验，不同时调奖励/PD|
|跨种子出现一致的目标角漂移，且辅助头贡献与退化方向相符|将“归一化后辅助头组合系数”作为候选单变量，设计下节对照；仍需物理结果检验|
|梯度投影不一致或无法解释早期偏离|保留否定/不确定结果，继续定位状态反馈和实际接受参数步；不据个别负余弦关闭辅助头|
|需要子步接触/位置才能解释某个失稳前事件|先指出已有数据缺口，再为该事件登记最小同动作回放；不能用 CPU 时序猜测真实冲量|

CPU 交付应包含：可复算入口、输入 SHA-256 清单、逐种子 JSON/CSV、目标角热图、早期状态曲线、梯度映射核验，以及明确选择哪个分支的报告。建议报告名 `standing_drift_diagnostic`，完整大文件继续留服务器，聚合图表和计划更新同步到仓库。

## 3. 条件满足后的小规模训练对照

以下只是后续候选设计，**本次规划不启动训练**；CPU 报告确定干预变量后再冻结新清单。

- 固定载荷候选初始化、三个训练种子和原四起点。对照组与实验组从匹配的新初始网络及相同优化器/RNG 状态开始，不从已退化的 final checkpoint 接续。
- 若选择辅助头贡献，唯一实验变量为归一化后的 Actor 头组合系数（例如 λ=1 对 λ=0）；Critic 各头、原奖励、PD 80/2、物理、终止和 1000 更新学习率日程保持。记录 KL、实际接受步数及梯度范数，解释系数变化对步长的影响。
- 首个停止点可设为两组×3 种子×16 环境×24 步×20 更新，训练最多 **46080 transitions、120 次 PPO 更新**。它只用于检查方向，不保证获得稳定站立。
- 训练后的独立匹配评估保持 initial/final×两种动作模式×四起点×最多 10 s：24 个任务，最多 **48000 transitions**。两部分合计上限 **94080 transitions**；向量环境中已经结束的起点仍计入实际推进预算。
- 采用新的训练清单、源码/配置指纹和评估目录，不能复用旧冻结评估器去静默接受已改变训练协议的 checkpoint。CPU 测试覆盖系数默认值、唯一变量、预算和 checkpoint 配对。
- 到预算即停止并释放 GPU，不自动延长到 100/200/500 更新；非有限值或明确接口错误立即保存并停止。行为差也如实保留，不按结果挑选种子重跑。
- 判断时同时看逐种子首次时长、10 s 完成、共同窗口倾角/关节/身体误差，以及速度/估计力矩尾部。若只有单个种子或某一指标变好，不宣称整体学习收益。

## 4. 后续扩规模条件

先获得多种子的配对行为改善，再争取四起点可重复完成 10 s，并实际覆盖 timeout 路径。满足这些工程条件后，才引入经验证的小幅动作，随后扩展参考库和正式 Stage 1。当前参考 v4 仍 `training_approved=false`；其残余支撑、速度、插值和求解问题作为独立数据质量任务处理。
